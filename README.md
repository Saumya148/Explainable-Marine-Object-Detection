# Explainable Marine Object Detection

## Overview
Marine object detection using YOLOv8 for underwater ecosystem monitoring.

## Technologies
- Python
- YOLOv8
- PyTorch
- OpenCV
- ByteTrack

## Objects Detected
- Fish
- Diver
- Reef
- Plants
- Robot
- Wreck
- Seafloor

## Performance

Precision : 70%

Recall : 51%

mAP@50 : 55.5%

mAP@50-95 : 40%
